# Laboratorio 1 de Estructura de Computadores

## Descripción

Desarrollo del laboratorio de simulación y optimización de un programa en un procesador MIPS segmentado.

El programa calcula la operación:

**Y[i] = A × X[i] + B**

sobre un vector de 8 elementos. Se analizan los riesgos de datos y los stalls del pipeline, y se optimiza el código mediante la reordenación de instrucciones.

## Archivos

- `programa_base.asm`: código original del laboratorio.
- `programa_optimizado.asm`: código optimizado para reducir los stalls.

## Herramienta

El programa fue desarrollado y simulado utilizando MARS 4.5 (MIPS Assembler and Runtime Simulator).
